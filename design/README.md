# Designfilerna

Arbetskopiorna bakom designcanvasen **CLEARANCE Designsystem**
(https://claude.ai/code/artifact/2783232e-0a62-4cd9-9d60-df38f237157a):
åtta artboards (`*.dc.html`) och layouten (`canvas.json`), byggda ur
produktens egna tokens – Archivo/DM Sans, 6 px radie, registerblå
`hsl(211 72% 27%)`, fristfärgen `hsl(8 74% 36%)` som bara bär lagstadgade
datum, platta ytor utan gradienter.

De ligger i repot av ett skäl: arbetskopior utanför versionskontrollen har
försvunnit i miljöåterställningar två gånger. Canvasen på länken är den
publicerade vyn; de här filerna är källan att utgå från vid nästa ändring.
Uppdateringsvägen är att redigera filerna här och publicera om canvasen –
inte att redigera i den publicerade sidan och låta repot halka efter.
